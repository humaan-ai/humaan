## Start Locally

Use the CLI to import, inspect, verify, and export recordings without a cloud
account. For an integration in another language, invoke the CLI with `--json` and
handle its exit status. Rust contributors can also use the shared engine from a
source checkout.

Humaan is in early alpha. Pin the tool or source revision used by an integration
and check format versions before consuming saved data.

For project concepts and storage details, start with the
[Assembly Guides](https://humaan.ai/docs).
