# Deployments

Deployments manages saved policies, physical robot profiles, and telemetry sessions. The current workflow is **Limited**: policy assignments are local records, and Live Link is read-only.

## Policies and assignments

Register a completed training run through **Manage policy in Deployments**, or **Policies → Add trained policy**. A policy retains its source run, robot snapshot, controller, and simulation evaluation.

Select a robot profile to check configuration compatibility and save an assignment. Assignment history supports restoring an earlier selection. Assigning or restoring does not start a policy or roll back a physical runtime.

## Robots and Live Link

Create a robot profile pinned to a Builder version and map calibrated telemetry channels to its joints. Live Link displays measured positions through a local telemetry bridge. A hardware-specific reader is required; the bridge does not send motor commands.

## Sessions

Record a session to capture converted joint positions and local receipt timestamps, then stop and save before closing the application. Sessions retain the robot definition and mapping for playback. Capture is limited to 10,000 samples and does not include synchronized camera data.

## Boundaries

Physical policy execution, direct SO-101 USB/calibration support, and automatic session ingestion into the next learning Loop are not provided by this workflow. A matching robot configuration and simulation evaluation do not establish hardware validation.

For bridge setup and implementation details, see the [desktop guide](https://github.com/humaan-ai/humaan/blob/v0.0.1-alpha.2/apps/desktop/README.md#deployments-read-only-live-link).
