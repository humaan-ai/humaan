# Reference

Use these references when inspecting saved files or building an integration. Workflow guides live under the corresponding workspace sections.

## Current project contracts

- [Project structure](../projects/structure.mdx) — storage locations and file responsibilities.
- [Project schema](../projects/schema.mdx) — the supported version 1 identity manifest and validation rules.

## Recording and learning-set formats

- [Recording format](https://github.com/humaan-ai/humaan/blob/v0.0.1-alpha.2/specs/recording-format/README.md) — original artifacts, integrity checks, and review history.
- [Learning-set format](https://github.com/humaan-ai/humaan/blob/v0.0.1-alpha.2/specs/learning-set-format/README.md) — immutable curation snapshots and exports.

Each format has its own version. Desktop storage locations are evolving implementation details, not stable interchange contracts.

## Design proposals

[Proposed project format](../projects/proposed-format.mdx) describes an unsupported future layout and version 2 manifest. It requires implementation and migration before use; do not copy that manifest into a current project.

See [CLI](https://humaan.ai/resources/cli), [API](https://humaan.ai/resources/api), [SDKs](https://humaan.ai/resources/sdks), and [Changelog](https://humaan.ai/resources/changelog) for developer tooling and release information.
