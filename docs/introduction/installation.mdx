# Installation

Humaan Studio provides the desktop workspace. Humaan CLI provides project and recording commands. Core local workflows do not require a cloud account.

## Humaan Studio

Choose a build for your operating system from [Humaan downloads](https://humaan.ai/download). After installing and opening Studio, choose **Create New** or **Open Project**.

For building Studio from source, follow the [desktop development guide](https://github.com/humaan-ai/humaan/blob/v0.0.1-alpha.2/apps/desktop/README.md), including its platform prerequisites. The frontend development server alone does not provide native project operations.

## Humaan CLI

Follow the [CLI installation and command reference](https://humaan.ai/resources/cli). Studio and CLI share project identity and recording formats; CLI commands do not cover every Studio workflow.

## Local simulation runtime

In Studio, open **Settings → Tools → MuJoCo → Install MuJoCo**. Setup downloads a managed environment and requires internet access. Local simulation can run offline after installation.
