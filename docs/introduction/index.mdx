# Introduction

Humaan connects robot design, simulation, learning, and policy management in a local workspace. Build and version an embodiment, run experiments, inspect evidence, and use the results to guide the next improvement.

## Start here

- [Install the tools](installation.mdx) for Studio or CLI workflows.
- [Run your first robot experiment](first-experiment.mdx) in Studio.
- [Understand the core concepts](../core-concepts/index.mdx), including Experiences and Loops.
- [Create or open a project](../projects/index.mdx).

## Explore the platform

[Builder](../builder/index.mdx) assembles and configures robots. [Simulation](../simulation/index.mdx) runs saved versions. [Experiences](../experiences/index.mdx) organizes recording review, learning sets, and training experiments. [Deployments](../deployments/index.mdx) manages policies, robot profiles, and read-only telemetry. [Compute](../compute/index.mdx) explains local and remote execution.

Use [Reference](../reference/index.mdx) for storage layouts, schemas, and explicitly marked design proposals. CLI, API, SDK integration, and release notes live in [Developer Resources](https://humaan.ai/resources).

## Capability status

Humaan is in early alpha. **Available** means implemented within the described scope; **Limited** means important workflow boundaries remain; **Preview** means an interface or sample exists without connected execution; **Planned** means not currently usable. These labels do not establish production readiness or physical hardware validation.

Local simulation and joint-feedback training are limited workflows. Physical policy execution and automatic feedback into the next Loop are planned. Read each workspace's boundaries before starting.
