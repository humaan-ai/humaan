# What Is Humaan

Humaan is an open-source workspace connecting robot design, simulation, learning, and policy management. Studio provides the interactive workflows; CLI supports project identity and recording operations.

Start with [Introduction](index.mdx) for platform navigation and capability status. Read [Core concepts](../core-concepts/index.mdx) for modules, embodiments, Experiences, Loops, recordings, and policies, or follow [First robot experiment](first-experiment.mdx).
